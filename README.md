# Stock Query App

This project was bootstrapped with [Create React App](https://github.com/facebook/create-react-app).

## Overview

The Stock Query App allows users to search for real-time stock data by ticker symbol and view key financial metrics. Users can also favorite stocks and filter them by industry.

## Features

- Search for a stock using its ticker symbol
- Display financial metrics:
  - Growth Rate (calculated from net income over time)
  - P/E Ratio
  - Growth over P/E
  - 52-Week High and Low
  - Current Stock Price
- Save stocks to a favorites list
- Store and filter favorites by industry

## Technologies Used

- React
- JavaScript
- CSS
- [Alpha Vantage API](https://www.alphavantage.co/)

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/ivan-newton/Stock-Query-App.git
   cd Stock-Query-App
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the app:
   ```bash
   npm start
   ```

4. Open your browser to [http://localhost:3000](http://localhost:3000)
